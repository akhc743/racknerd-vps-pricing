## RackNerd 10美元VPS 适合谁，不适合谁

聊点实在的，免得你买完发现不是自己想要的。

**适合的场景：**

- 个人博客、静态站、小型 WordPress（1GB 那档往上比较稳）；
- 自建轻量代理节点（Xray、Hysteria2、Sing-box 都行，768MB 就够）；
- 学习练手：Linux 命令、Docker、K3s 单节点、自托管各类小服务；
- 做监控探针、定时爬虫、TG bot 后端这种"长期跑但不吃资源"的活；
- 给主站做冷备、做跳板机、做 DNS over HTTPS 中转。

**不太适合的场景：**

- 高并发电商、数据库主节点——SSD 是 RAID-10 共享盘，不是 NVMe 独享，IOPS 上不去；
- 对中国大陆有强直连需求的——RackNerd 走的是国际线路，电信回程多走普通 BGP，没有 CN2 GIA 那种丝滑感，晚高峰可能会绕；
- 需要弹性扩缩容、按秒计费的——这是云厂商的活， RackNerd 是固定套餐年付制，逻辑不一样。

一句话总结：**它是"够用且便宜"的代表，不是"性能怪兽"的代表**。把它当工具用，它会让你很满意；把它和 AWS EC2 比，那是比错了对象。

## 买之前，几个我踩过/见过的坑

**1. 别只看首发价，要看续费价。**
很多低价 VPS 商家第一年便宜，续费翻倍。RackNerd 这点做得厚道——特供套餐是**价格锁定**的，续费和首发同价，不会偷偷涨。这也是为什么老用户把它叫"传家宝"，买到就是长期占坑。

**2. 机房别瞎选。**
中国大陆用户优先选**洛杉矶 DC-02**（亚太优化，库存最紧张），其次 DC-03、圣何塞、西雅图。东海岸的纽约、阿什本延迟会高一截，不太推荐给追求速度的人。欧洲机房（阿姆斯特丹等）适合面向欧洲访客的站点，不适合自用代理。

**3. 流量可以翻倍。**
RackNerd 有一个不太宣传的福利：下单后**提交工单申请流量翻倍**，很多套餐能从 2TB 直接变 4TB，永久生效。这个操作很多新手不知道，白白浪费了。

**4. 768MB 那档要会折腾。**
内存只有 768MB，装系统时别选默认的 Ubuntu Server 带一堆有的没的，选个精简版（比如 Debian netinst、Alpine），swap 给足，跑起来才顺。否则你装完发现开机就吃掉 500MB，那体验就很差。

**5. 别等"下一个节日更便宜"。**
RackNerd 一年十二个节都在促销，但**最便宜的那几款往往是黑五和元旦放出，卖完不补货**。等来等去，等到的往往是"特供已售罄"的提示。看到合适的就入手，别贪。
